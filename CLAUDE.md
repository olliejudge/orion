# Orion

Single Go binary that serves a live, animated bubble map of a git repo (all worktrees) in the browser. Frontend is TypeScript + PixiJS, built with Vite and embedded via `go:embed`. Released with GoReleaser to a Homebrew tap.

Design spec: `docs/superpowers/specs/`. Implementation plans: `docs/superpowers/plans/`.

## Git workflow (follow strictly)

- `main` is protected. Never commit to it directly — every change lands via a PR.
- One short-lived branch per task: `<type>/<short-kebab-desc>` (e.g. `feat/fsevents-watcher`, `fix/rename-detection`).
- Parallel agents each work in their own git worktree under `.claude/worktrees/` (gitignored), one branch per worktree. Never share a worktree between agents.
- Commit messages follow Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`, `ci:`, `build:`. Imperative mood, subject ≤ 72 chars, body explains *why*.
- Small, focused commits. Tests and lint must pass before each commit (see Commands).
- Rebase on `main` before opening a PR; PRs are squash-merged and the branch deleted.
- Never force-push `main`. Never rewrite history on a branch someone else is using.
- Never commit: build output, `node_modules`, `.superpowers/`, secrets, or anything from other repos.

## Privacy

This repo is public. Repos we test against locally may be private: never copy their file names, paths, contents, commit messages, author names or screenshots into this repo — not in fixtures, tests, docs, PR descriptions or commit messages. Test fixtures are synthetic repos generated by test helpers.
